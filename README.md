## 🎯 About

This repository contains hands-on exercises and projects from **Module B** of a web development bootcamp curriculum. It focuses on backend development fundamentals — building REST APIs, database integration, authentication, and server-side logic.

---

## 📚 Topics Covered

| # | Topic | Description |
|---|-------|-------------|
| 1 | **Node.js Fundamentals** | Core modules, event loop, file system, streams |
| 2 | **Express.js** | Routing, middleware, request handling, error handling |
| 3 | **REST API Design** | HTTP methods, status codes, resource naming |
| 4 | **Database Integration** | MongoDB, Mongoose ODM, CRUD operations |
| 5 | **Authentication** | JWT, bcrypt, session management |
| 6 | **Validation** | Input validation, sanitization, error responses |
| 7 | **File Uploads** | Multer, cloud storage integration |

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- MongoDB instance (local or Atlas)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/manuskhan23/Module-B.git
cd Module-B

# Install dependencies
npm install

# Set up environment variables
# Create .env file with required configs

# Run the project
npm start
```
